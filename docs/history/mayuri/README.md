# Mayuri History

This directory preserves historical documentation from the Mayuri lab, which was decommissioned in October 2026.

The files here document the environment, readiness assessments, validation program, campaign planning, and detection-quality decisions that supported earlier live-validation work.

## Interpretation

- Historical live-validation records retain their original provenance and status.
- Infrastructure-readiness statements in these files describe the lab at the time they were written.
- They should not be interpreted as current infrastructure availability.
- New portfolio work should not depend on Mayuri being available.

Current repository status is tracked under [docs/current-state](../../current-state/).


## Final preserved milestones

The archive includes the final Mayuri-era Detection Cycle 1 material covering PT-2026-014 (T1105), PT-2026-015 (T1218.005), three completed threat hunts, and the bounded benign campaign used to correlate download-to-execution behavior.
