# Forensic acquisition

**Capability maturity: Planned**

This capability will provide repeatable endpoint acquisition profiles for investigation triage, targeted artifact collection, and explicitly authorized full acquisition.

## Required implementation evidence

- approved scope and collection objective
- documented tool, version, command, and target
- volatility and operational-impact assessment
- private storage and transfer path
- integrity hashes before analysis
- acquisition verification and failure notes
- a sanitized collection manifest linked to an investigation

The governing method is [forensic acquisition](../../docs/workflows/forensic-acquisition.md). Existing endpoint investigations show source-driven analysis, but they do not yet establish a complete reusable acquisition capability.
