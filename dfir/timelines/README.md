# Timeline analysis

**Capability maturity: Planned**

This capability will turn evidence from multiple sources into timestamp-normalized, source-cited investigation timelines.

## Required implementation evidence

- original and normalized timestamps
- timezone and clock-offset notes
- evidence identifiers for every material row
- clear separation of observation and interpretation
- documented correlation keys and duplicate handling
- gaps, uncertainty, and inferred ordering marked explicitly
- sanitized timeline output linked to a completed case

Follow the [timeline analysis workflow](../../docs/workflows/timeline-analysis.md). `MAY-IR-005` is the planned full Windows DFIR case intended to demonstrate this capability end to end.
