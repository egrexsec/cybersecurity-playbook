# Memory forensics

**Capability maturity: Planned**

No memory-forensics result is currently claimed. Future work will cover safe acquisition, integrity verification, framework setup, triage, cross-source validation, and public-safe reporting.

## Maturity path

- **Planned** — workflow and acceptance criteria documented.
- **Installed** — approved acquisition and analysis tooling is available with private encrypted storage.
- **Verified** — a known test image is processed reproducibly and expected artifacts are recovered.
- **Live validated** — an approved lab investigation uses memory evidence with documented custody, analysis, and sanitized conclusions.

Follow the [memory triage workflow](../../docs/workflows/memory-triage.md). Memory images and sensitive extracts must remain private.
