# Evidence handling

**Capability maturity: Installed**

The repository's **public sanitization and public-safe derivation practice is Verified** through existing published validation records. The broader end-to-end evidence-handling capability remains Installed until a completed case demonstrates the private ledger, source/working-copy separation, integrity checks, and evidence-ID traceability together.

## Controls

- raw evidence and full acquisitions remain private
- collection and transfer metadata is recorded in a private evidence ledger
- hashes or stable source references preserve traceability
- originals and analysis copies remain separate
- public derivatives are reviewed for secrets, personal data, and infrastructure exposure
- findings cite evidence identifiers, not unstored recollection
- AI output is not evidence and cannot replace source validation

Use the [evidence handling workflow](../../docs/workflows/evidence-handling.md) for required ledger fields and publication review.
