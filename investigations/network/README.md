# Network investigations

**Capability maturity: Planned**

Network investigation coverage will support endpoint and identity cases with DNS, connection, protocol, and cross-host pivots. The repository does not currently claim a verified packet-capture or network-forensics workflow.

## Planned capability

- identify the authoritative source and collection boundary
- preserve timestamps, sensor context, flow direction, and address translation assumptions
- correlate network activity with endpoint process and identity evidence
- document filtering, time-window, and retention limitations
- publish only sanitized excerpts and derived observations

A network capability moves beyond Planned only after the collection and correlation workflow is exercised and evidence-backed.
